# 健康体检独立模块生产切换说明

更新时间：2026-07-24  
模块 ID：`physical-examination`  
代码基线：T10-P 独立模块分支

## 1. 目标与边界

本增量使机构能够单独部署健康体检生产控制面，不加载急救、用血或影像业务模块。独立入口为：

```text
physical-examination-standalone.html
```

入口只加载以下体检域脚本：

```text
physical-examination-standards.js
physical-examination-production.js
physical-examination-standalone.js
```

独立控制面负责验证字段映射、接入回执、报告签名、原件扫描归档、异常闭环、现场双人签署、独立冒烟和回退演练。它不提供统一身份、生产数据库、对象存储、CA、短信、预约或家医系统本身；这些能力由部署机构通过真实回执接入。

## 2. 生产控制面

`physical-examination-production.js` 是浏览器和 Node 均可使用的 UMD 模块，不依赖公共 `server.js`。主要接口如下：

| 接口 | 作用 |
|---|---|
| `mapSourceReport(payload, profileId, options)` | 将体检中心或医院字段映射为统一报告并生成映射回执 |
| `validateSourceMappingEvidence(evidence)` | 校验字段字典版本、样例请求/响应、端点和载荷摘要 |
| `validateIntegrationReceipt(receipt)` | 校验验签、映射、落库、幂等和生产回执 |
| `validateReportSignatureContract(report)` | 校验 WS/T 483.16 文档画像及 WS/T 847 生产签名 |
| `createAbnormalClosure(report, context)` | 按异常项生成居民待办和家医复核建议 |
| `applyAbnormalClosureAction(...)` | 执行确认、通知、复查、家医随访、关闭状态机 |
| `validateArchiveEvidence(evidence)` | 校验原件摘要、版本、扫描、加密和不可变留存 |
| `validateIndependentSignoff(signoff)` | 校验现场证据提交人与复核人职责分离 |
| `validateStandaloneSmoke(smoke)` | 校验独立入口、体检域文件及五类冒烟探针 |
| `validateRollbackGate(rollback)` | 校验快照、制品摘要、回退演练、RTO和独立批准 |
| `buildGoLiveDecision(bundle)` | 汇总为 `GO` 或 `NO-GO` |

## 3. 源系统字段映射

### 3.1 体检中心

画像：`exam-center-v1`，版本：`1.0.0`。

支持标准字段及常见别名，例如：

- `personIndex` / `person.index` / `mpiId`
- `externalId` / `checkupId` / `documentId`
- `institutionId` / `organization.code` / `orgCode`
- `examDate` / `checkupDate`
- `findings` / `items`

### 3.2 医院

画像：`hospital-v1`，版本：`1.0.0`。

支持标准 JSON、医院文档结构及大写交换字段，例如：

- `personIndex` / `patient.mpiId` / `MPI_ID`
- `externalId` / `document.id` / `DOCUMENT_ID`
- `institutionId` / `organization.code` / `ORG_CODE`
- `examDate` / `document.serviceDate` / `EXAM_DATE`
- `findings` / `document.entries` / `ITEMS`

每次映射必须同时提交来源载荷 SHA-256。缺少居民标识、机构、外部标识、报告号、体检日期、结论或摘要时，映射回执为 `rejected`。

## 4. 报告签名契约

生产报告必须满足：

1. 文档画像为 `WS/T 483.16-2016`；
2. 七类文档章节完整；
3. 原文 SHA-256 为 64 位十六进制；
4. 体格、检验、影像分项均有关联医师、执业证号、时间和签名引用；
5. 医学文档签名为 `WS/T 847-2024`，模式为 `production` 或 `external-production`；
6. 使用 SM2、SM3、ES-T 和可信时间戳；
7. 证书链、吊销状态和时间戳均已验证；
8. 签名覆盖文档摘要与原文摘要完全一致。

HMAC 传输验签不能代替医学电子文档签名。演示签名、演示证书、摘要不一致或签名对象缺失均直接阻断。

## 5. 异常通知、复查与家医随访

闭环顺序固定为：

```text
医师确认
  → 居民通知真实送达
  → 复查预约/目标机构
  → 家庭医生随访结果
  → 证据关闭
```

控制规则：

- 通知前必须完成医师确认；
- 通知必须有 `receiptId`、渠道、送达状态和送达时间；
- 复查必须有预约引用、目标机构和日期；
- 家医随访必须有团队、随访引用和结果；
- 家医建议只触发“复核或签约建议”，`autoSign=false`，不得代替居民同意；
- 任一步缺少证据时禁止关闭；
- 重开后原关闭证据失效，必须重新闭环。

## 6. 原件归档与恶意文件扫描

每份生产报告的原件证据至少包含：

- 对象 ID 和不可覆盖的版本 ID；
- 文件 SHA-256、MIME 类型和大小；
- 校验和验证结果；
- 服务端扫描结果 `clean`；
- 扫描引擎、版本和完成时间；
- 静态加密；
- 不少于 15 年的不可变留存；
- 可审计的归档回执引用。

`infected`、`pending`、缺少扫描引擎、可变对象、留存不足或校验失败均为生产阻断。

## 7. 独立冒烟

独立冒烟证据必须包含：

1. `static-entry`：独立 HTML 可访问；
2. `field-mapping`：体检中心/医院样例完成映射；
3. `signature-contract`：生产签名契约通过；
4. `archive-scan`：原件归档和扫描回执通过；
5. `care-closure`：异常五步闭环通过。

运行清单不得出现急救、用血或影像模块引用。冒烟记录需保存执行时间、探针回执和总证据引用。

## 8. 回退门禁

回退证据必须包含当前版本、上一版本、制品 SHA-256、数据快照引用、演练编号、演练时间、目标 RTO、实际恢复时长和对账结果。制备人与批准人必须不同。

以下任一情况保持 `NO-GO`：

- 没有上一可用版本或快照；
- 未做回退演练；
- 恢复时间超过目标 RTO；
- 回退后数据对账失败；
- 制备人与批准人为同一责任人。

## 9. Go-Live 判定

`buildGoLiveDecision` 只有同时满足以下条件才返回 `GO`：

1. `environment=production`；
2. 启用的体检中心和医院来源均有字段映射证据；
3. 两类来源均有真实生产落库回执；
4. 至少一份报告通过生产签名契约；
5. 每份报告都有原件扫描归档证据；
6. 异常报告已完成通知、复查和家医随访闭环；
7. 两类来源均完成现场证据独立核验；
8. 独立冒烟全部通过；
9. 回退演练及独立批准通过。

现场证据未签收时，即使代码检查全部通过，结论仍为 `NO-GO`。

## 10. 验证命令

无需修改公共 `package.json`：

```powershell
node --check physical-examination-production.js
node --check physical-examination-standalone.js
node --check scripts/physical-examination-standalone-readiness.js
node --test test/physical-examination-production.test.js
node scripts/physical-examination-standalone-readiness.js
```

专项脚本生成：

```text
release/physical-examination-standalone-readiness-report.json
release/physical-examination-standalone-readiness-report.md
```

## 11. 外部依赖与现场阻断

- 体检中心、医院的生产端点、专线/白名单、机器身份和非占位密钥；
- WS/T 847 生产 CA、签名服务、时间戳和证书状态服务；
- 对象存储、恶意文件扫描、不可变留存、备份和恢复；
- 短信/应用消息真实送达回执；
- 复查预约与家庭医生随访回执；
- 机构责任人、卫生行政复核人双人现场签署；
- 生产制品、快照和正式回退演练。

这些证据不能由演示数据或静态页面替代。
