# 数智医院标准平台 v0.21 公共卫生证据与双人复核闭环

## 一、建设目标

v0.21 承接 v0.20 公共卫生运营工作台，补齐现场证据登记、独立签收、事件关闭门禁和医院授权范围。公共卫生专业系统继续保存事实数据与原始附件，数智医院协同账本仅保存外部编号、最小化摘要、内容摘要和审计关系。

## 二、已实现能力

### 2.1 现场证据账本

- 公共卫生协同账本升级至 schema v3。
- 证据与事件通过 `incidentId` 和 `evidenceIds` 双向引用。
- 证据仅保存类型、外部编号、最小化摘要和 `sha256:` 内容摘要。
- 原始附件、密钥、签名、nonce、凭据、证书和业务载荷不得写入协同账本。
- 证据状态包括 `submitted`、`accepted` 和 `rejected`，任何状态均不自动成为生产证据。

### 2.2 双人签收与并发控制

- 证据提交人不得签收或驳回自己的证据。
- 证据复核同时校验 `expectedEvidenceRevision` 和 `expectedIncidentRevision`。
- 证据提交、签收和驳回都会推进事件修订号并写入事件审计与证据审计。
- 已签收或待签收的同类证据不能重复登记；驳回后可按新修订号重新提交。

### 2.3 分级关闭门禁

| 事件级别 | 必须独立签收的关闭证据 |
| --- | --- |
| P2 | 真实业务回执摘要、现场接口联调记录 |
| P1 | P2 全部证据、生产审批编号 |
| P0 | P1 全部证据、灾备与回退演练编号 |

事件仍按“待核查 -> 处置中 -> 待复核 -> 已关闭”推进。证据不齐时 `verify-close` 返回 `PUBLIC_HEALTH_CLOSURE_EVIDENCE_REQUIRED`，不得跳过业务复核或直接改写终态。

### 2.4 医院授权范围

- 市级平台和卫健委账号按身份目录授权三家试点医院。
- 区级账号仅授权 `H000003`。
- 查询、导出、事件登记、状态推进、SLA 升级、证据登记和证据复核使用同一医院范围。
- 显式查询越权医院返回 `PUBLIC_HEALTH_HOSPITAL_SCOPE_FORBIDDEN`；越权访问事件或证据按不存在失败关闭。

## 三、正式接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/digital-hospital/public-health/coordination` | 获取授权医院范围内的事件、证据、门禁和统计 |
| `POST` | `/api/digital-hospital/public-health/incidents` | 登记最小化协同事件 |
| `POST` | `/api/digital-hospital/public-health/incidents/{incidentId}/actions` | 推进生命周期、执行独立关闭或 SLA 升级 |
| `POST` | `/api/digital-hospital/public-health/incidents/{incidentId}/evidence` | 登记关闭证据摘要 |
| `POST` | `/api/digital-hospital/public-health/evidence/{evidenceId}/actions` | 独立签收或驳回证据 |
| `GET` | `/api/digital-hospital/public-health/incidents/export` | 导出授权范围内的安全 JSON/CSV |

## 四、试点工作台

- “事件处置”显示每个事件的关闭证据完成度和是否可关闭。
- “证据签收”展示证据编号、类型、提交人、复核人、状态和关闭缺项。
- 可登记下一项缺失证据，并通过切换独立角色执行签收或驳回。
- JSON/CSV 导出包含关闭门禁和安全证据摘要，不包含原始附件。
- 移动端表格保持自身横向滚动，不扩大页面宽度。

## 五、投产边界

1. 页面和种子记录是受控验收样例，不代表真实医院、专业系统或审批机构已经签字。
2. `productionEvidence` 和 `productionReady` 始终为 `false`。
3. 真实机构目录、统一身份、现场回执、生产审批、灾备演练和多方上线签字仍需现场接入。
4. 证据摘要变化后必须重新提交和独立签收，不能沿用旧结论。

## 六、下一阶段

1. 将医院授权编码替换为现场机构目录和统一身份声明。
2. 对接受控对象存储或电子档案系统，登记不可变附件引用和保全回执。
3. 增加证据到期、撤销、范围变化失效和重新签收机制。
4. 将证据缺项和签收超时接入统一任务中心及值班告警。
