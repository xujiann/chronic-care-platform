# 公共卫生信息化系统全景图集

生成日期：2026-07-12
适用范围：已纳入平台公共卫生、医防融合、居民服务、医疗机构协同、数据治理、安全审计与上线治理能力。

## 阅读说明

本图集以逻辑架构和业务责任为主，不替代网络拓扑、IP 地址、密钥、供应商接口地址或现场签字材料。所有标记为“待现场联调”的节点均不构成生产上线证明。

| 阅读顺序 | 图集目的 | 主要读者 |
|---|---|---|
| 1-4 | 看清系统范围、业务能力和公卫闭环 | 卫健管理、疾控、项目管理 |
| 5-9 | 看清数据、接口、权限和居民服务路径 | 信息中心、业务处室、医院 |
| 10-14 | 看清医防协同、质控、安全和部署边界 | 医疗机构、等保、运维团队 |
| 15-17 | 看清监控、灾备和上线治理 | 运维、应急、上线指挥组 |

## 6. 预约回调与人工对账时序图

```mermaid
sequenceDiagram
  participant Resident as 居民端
  participant Portal as 平台服务
  participant Gateway as 集成网关
  participant External as HIS 支付 医保
  participant Institution as 机构端
  participant Audit as 审计与证据

  Resident->>Portal: 预约、支付、报到或退号请求
  Portal->>Audit: 写入服务操作审计
  External->>Gateway: HMAC 回调与外部流水号
  Gateway->>Gateway: 验签、幂等、状态顺序校验
  Gateway->>Portal: 更新预约订单与居民消息
  Portal->>Audit: 写入回调与数据访问审计
  alt 回调异常
    Gateway->>Institution: 死信原因与重试任务
    Institution->>Gateway: 三次内重试与处理备注
    Gateway->>Institution: 超限转人工对账
    Institution->>Audit: 责任人、SLA、补偿凭据、结案或复开
  else 正常回调
    Portal-->>Resident: 展示订单状态与就诊时间线
  end
```

## 图集使用建议

1. 面向领导汇报：优先使用第 1、3、4、17 图。
2. 面向医院和疾控联调：优先使用第 5、6、7、11 图。
3. 面向信息中心和等保测评：优先使用第 2、13、14、15、16 图。
4. 面向居民服务运营：优先使用第 8、9、10 图。
5. 正式上线评审时，所有“待现场联调”节点必须替换为真实接口、验收记录、签字材料和生产监控证据。
