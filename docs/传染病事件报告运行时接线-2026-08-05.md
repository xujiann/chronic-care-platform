## API

```text
POST /api/public-health/infectious-reporting-cases
GET  /api/public-health/infectious-reporting-cases/:id
POST /api/public-health/infectious-reporting-cases/:id/actions
```

接收命令至少包含：

```json
{
  "externalEventId": "stable-external-event-id",
  "publicHealthEventId": "existing-public-health-event-id",
  "reportId": "existing-disease-report-id",
  "sampleNo": "existing-laboratory-sample-no"
}
```

人工动作接口当前仅向卫健委角色开放。动作体至少包含：

```json
{
  "action": "validate-event",
  "idempotencyKey": "stable-command-key",
  "expectedVersion": 1
}
```

## 外部回执边界

`record-receipt` 不允许通过人工动作 API 写入。疾控直报的接受或拒收回执必须经过已配置的签名回调、时间窗、重放防护和绑定校验后，再由受信运行时推进领域状态。当前未完成该受信回调到业务实例的绑定，因此 API 不会伪造完整七阶段闭环。

仓库中的验收场景只证明状态机软件行为；真实回执、疾控复核、现场证据和签字仍是外部门禁。缺少这些材料时：

```text
businessClosureComplete=false
productionReady=false
```
