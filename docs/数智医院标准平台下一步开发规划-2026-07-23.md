# 数智医院标准平台下一步开发规划

日期：2026年7月23日

## 一、当前能力基线

平台已具备六域规范台账、效力和生命周期管理、标准版本变更影响闭环、六域控制整改、最小化证据、独立复核、医院自评、省级初审、专家复核、评价预评、生产证据包、上线指挥简报及四方正式割接审批。仓库内能力达到试点上线软件基线，正式生产仍受真实接口、真实数据、安全测评、灾备演练和现场签字约束。

## 二、P0：试点现场可运行（0-30天）

| 事项 | 主要开发 | 验收口径 |
| --- | --- | --- |
| 属地标准增补 | 增加省市政策导入、适用机构、地区、效力日期和冲突校验 | 试点地区政策100%完成来源复核和控制映射 |
| 标准原文与条款解析 | 接入受控文件存储，形成条款、数据元、指标和控制的版本化映射 | 新旧版本差异可追溯，原文摘要与文件校验值一致 |
| 现场证据接入 | 对接医院材料库或对象存储，增加查毒、摘要、留存和访问授权 | 现场证据可验证、可撤销、无患者可识别信息进入台账 |
| 真实评价采集 | 完成HIS/EMR/LIS/PACS/HRP试点接口字段映射和回执对账 | 成功、失败、重试、补偿和人工对账全部通过 |
| UAT与上线运行 | 完成医院填报、管理初审、专家复核、整改和抽查全角色演练 | P0现场清单、生产告警、回滚演练和四方签字完成 |

## 三、P1：评价运营深化（31-60天）

| 事项 | 主要开发 | 验收口径 |
| --- | --- | --- |
| 指标版本迁移 | 评价方案升级时自动分析任务、评分、证据和整改影响 | 历史结果不被覆盖，新周期迁移可回放 |
| 证据治理 | 增加证据指纹、重复引用检测、过期策略、抽样计划和争议处理 | 重复、过期和被替代证据无法通过门禁 |
| 专家评审治理 | 增加专家回避、冲突声明、抽签、双评差异和仲裁 | 评审分配与结论全程可审计 |
| 区域对标分析 | 按机构类型、等级和区域形成脱敏分位、短板与整改趋势 | 不泄露单院敏感数据，指标口径可追溯 |
| AI治理控制 | 建立模型卡、审批、版本、漂移、人工复核和停用证据 | 临床AI启用前控制项全部通过现场验证 |

## 四、P2：规模化运营（61-90天）

1. 建立标准更新订阅、定期复核提醒、责任升级和季度标准运营报告。
2. 支持多省、多级卫健组织、专家库和试点批次的配置化运营。
3. 完成大规模采集性能、容量、容灾、备份恢复和跨区故障切换验证。
4. 建立评价结果发布审批、异议申诉、复核更正和年度归档流程。
5. 将标准符合度、整改时效、证据质量和接口稳定性纳入平台运营驾驶舱。

## 五、阶段门禁

1. P0退出：试点机构真实接口和证据链通过，P0-01至P0-10现场清单完成，允许受控灰度运行。
2. P1退出：评价版本迁移、证据治理、专家治理和区域分析完成一轮真实周期验证。
3. P2退出：完成容量、灾备、跨区域权限和运营制度验收，具备规模化推广条件。
4. 任一阶段不得以演示数据、模拟回执或仓库内报告替代医院、厂商、测评机构和责任部门的正式证据。
