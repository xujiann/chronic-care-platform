# 居民端下一步开发优先级

本计划用于承接居民端已完成的手机号验证码登录、二级页面导航、小程序/APP/PWA 预览、健康档案、电子病历、护理、陪诊、挂号、消息待办和移动端验收能力。后续开发按“先真实上线底座，再业务闭环，再运营推广”的顺序推进。

## P0 真实上线底座

| 事项 | 目标 | 验收证据 |
| --- | --- | --- |
| 生产短信网关 | 替换演示验证码，保留冷却、有效期、失败锁定和审计 | `SMS_GATEWAY_URL`、短信模板、发送回执、失败重试记录 |
| 实名与家庭关系核验 | 手机号登录后绑定真实居民、监护人和家庭成员授权范围 | 政务身份/OIDC 参数、家庭关系核验记录、越权访问测试 |
| HTTPS、隐私协议和移动端发布材料 | 满足小程序、APP、PWA 分发和安装要求 | 域名备案、HTTPS 证书、隐私协议、APP 签名、推送证书、崩溃监控 |
| 居民端上线门禁 | 每次发布前证明登录、导航、离线壳、预览和外部依赖边界可用 | `npm.cmd run citizen:launch-foundation`、`npm.cmd run launch:smoke`、真机验收截图 |

## P1 医疗数据只读接入

| 事项 | 目标 | 验收证据 |
| --- | --- | --- |
| 居民主索引与健康档案 | 接入真实居民主索引、公卫和基层慢病档案，只读展示 | 居民主索引映射表、样例居民脱敏数据、接口联调单 |
| EMR/LIS/PACS 摘要 | 接入门诊病历、检验检查、用药处方、影像索引和附件摘要 | HIS/EMR/LIS/PACS 契约、授权校验、审计日志 |
| 授权撤销强拦截 | 授权撤销后机构端、远程会诊和居民端复核同步生效 | 撤销后访问被拒测试、访问复核台账、安全事件记录 |

## P2 服务闭环深化

| 事项 | 目标 | 验收证据 |
| --- | --- | --- |
| 护理履约闭环 | 补齐知情同意、位置轨迹、护理记录、费用预估、质控回访和投诉处理 | 护理订单全流程样例、附件哈希、质控回访记录 |
| 陪诊履约闭环 | 接入医院接诊回执、陪诊师签到、保险合同附件、补贴结算和服务评价 | 医院回执、签到记录、保险附件、评价投诉闭环 |
| 挂号真实联调 | 接入 HIS/互联网医院号源、支付、医保电子凭证、退号和短信通知 | 号源锁定、支付/医保状态、取消退号回调样例 |

## P3 运营推广与持续优化

| 事项 | 目标 | 验收证据 |
| --- | --- | --- |
| 试点白名单与灰度 | 小范围开放真实居民，按机构、社区和服务类型分批扩大 | 灰度名单、日运行报告、问题闭环台账 |
| 消息推送与触达回执 | 打通短信、订阅消息、APP 推送和站内信，形成触达统计 | 送达回执、失败重试、居民确认记录 |
| 适老化与无障碍复核 | 保持 44px 以上触控、清晰状态、手势导航、大字模式和真机兼容 | 真机截图、可访问性检查、居民试用反馈 |

## 当前建议顺序

1. P0：先完成生产短信、实名/家庭关系、HTTPS/隐私/移动端发布材料。
2. P1：再接入健康档案、电子病历和影像附件摘要，只承诺只读可查。
3. P2：随后深化护理、陪诊、挂号真实履约闭环。
4. P3：最后扩大试点白名单，补齐消息触达、适老化反馈和运营质控。
