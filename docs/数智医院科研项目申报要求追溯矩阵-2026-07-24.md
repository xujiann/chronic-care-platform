# 数智医院科研项目申报要求追溯矩阵

## 建设目标

本轮开发将项目编码 `042020604` 的申报内容转化为平台可执行、可复核、可导出的验收对象，建立：

`委托任务 -> 六域 -> 平台模块/API -> 成果或量化指标 -> 证据引用与哈希 -> 独立复核 -> 研究报告`

平台实现证据用于证明研发基础和过程完成度，不自动替代委托单位、医院科研管理部门、伦理安全审查或正式验收意见。

## 申报要求与平台能力

| 申报要求 | 本轮平台落点 | 验收证据 |
| --- | --- | --- |
| 国家、省、医疗机构三级评价架构 | 三级架构任务及跨层级平台/API映射 | 三级业务架构、综合研究报告 |
| 六域指标与标准资产模型 | 六域和六级追溯矩阵 | 六域指标体系、指标字典 |
| 多源采集、数据核验与证据链 | 正式证据引用、摘要哈希、全过程状态 | 证据目录、数据完整率、证据可追溯率 |
| 医院自评与分级审核 | 登记、提交、独立复核、退回、撤销 | 评分审核规则、核心流程通过率 |
| 规则引擎与安全生产关键技术 | 现有平台模块、API和工程能力映射 | 原型、测试、操作手册、实施方案 |
| 长效运行与试点推广 | 五阶段里程碑和十一项量化指标 | 专家咨询、信效度、深度/扩展试点、整改闭环 |
| 2份研究报告和1套实施方案 | 作为一级必验收成果独立管理 | 正式成果文件、归档编号、独立复核记录 |

## 可操作入口

- 页面：`research-project-acceptance.html`
- 查询：`GET /api/research-project/acceptance-center`
- Markdown报告：`GET /api/research-project/acceptance-center?format=markdown`
- 证据动作：`POST /api/research-project/acceptance-items/:id/actions`
- 离线报告：`npm run research-project:acceptance`

### 专家咨询统计

- 轮次查询：`GET /api/research-project/expert-consultation`
- 建立轮次：`POST /api/research-project/expert-consultation/rounds`
- 登记匿名问卷：`POST /api/research-project/expert-consultation/rounds/:id/responses`
- 轮次定稿与独立复核：`POST /api/research-project/expert-consultation/rounds/:id/actions`
- 离线统计报告：`npm run research-project:expert-consultation`

平台对每份匿名问卷计算六项核心指标 I-CVI、三准则 AHP 权重和一致性比率 CR，并按已独立复核轮次汇总专家积极系数。专家代号入库前进行 SHA-256 摘要处理，不保存姓名、联系方式或患者信息。已复核轮次会自动形成专家轮次、积极系数、AHP CR 和最低 I-CVI 四项待提交验收证据，仍须按项目验收流程独立复核。

### 评价者间一致性

- 批次查询：`GET /api/research-project/rater-consistency`
- 建立批次：`POST /api/research-project/rater-consistency/batches`
- 登记匿名评价：`POST /api/research-project/rater-consistency/batches/:id/ratings`
- 批次定稿与独立复核：`POST /api/research-project/rater-consistency/batches/:id/actions`
- 离线统计报告：`npm run research-project:rater-consistency`

分类结论采用 Fleiss Kappa，连续评分采用双向随机、绝对一致、单次测量 `ICC(A,1)`。平台以所有已复核批次的最低系数对照 `Kappa/ICC >= 0.75` 验收目标。案例编号和评价者代号入库前均进行 SHA-256 摘要处理；复核来源撤销或发生变化时，已自动回填的验收证据同步失效。

## 证据流程

1. 医院或项目管理人员登记受控证据；量化指标同时登记实测值。
2. 平台计算目标是否满足，未达标指标不能提交验收复核。
3. 登记人提交独立复核。
4. 卫健管理端使用不同账号复核通过或退回补充。
5. 证据变化时撤销原复核结论并重新走完整流程。

正式项目验收状态只有在全部必需成果和指标完成独立复核后，才会变为 `ready-for-formal-acceptance-review`。

## 仍需现场形成的材料

- 项目负责人、专家组和协作试点单位正式名单。
- 两轮德尔菲咨询受控原始问卷、专家遴选依据及授权归档材料；平台保存匿名统计结果和证据摘要。
- 医院数据授权、伦理审查、安全审查及数据处理记录。
- 深度试点和不少于2家扩展试点的签字记录。
- 两份研究报告、一套实施方案及其院内审校和委托单位验收意见。
