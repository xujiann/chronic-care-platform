# 领域运行时上下文规范

版本：runtime-context-v1  
适用基线：`codex/governance-integration-20260803`

## 目标

路由域只能接收其显式声明的运行时能力。`src/http/routes/index.js` 是全局运行时对象进入领域路由的唯一投影点；领域路由不得自行回取全局对象。

## 约束

1. 每个上下文必须声明 `domain`、负责进程和有序依赖清单。
2. 投影时缺少任一依赖立即失败，额外依赖不得进入领域上下文。
3. 上下文对象与依赖清单均冻结，运行期间不可扩展。
4. 依赖清单必须与对应路由模块顶部的解构声明完全一致，并由自动化测试守护。
5. 跨域能力必须通过版本化契约登记，不得通过扩大领域上下文绕过边界。

## 验收

- 上下文依赖与路由解构完全一致。
- 缺失依赖在创建路由时失败，而非请求进入后才失败。
- 领域上下文中不存在未声明的全局能力。
- 所有路由顺序、API 行为与发布门禁保持不变。
