# 院前急救系统拓扑与流程图集

> 与 `emergency-service.js` 的状态机、`/api/emergency/*` 接口和急救上线门禁同步维护。

## 1. 业务全景拓扑

```mermaid
flowchart LR
  Citizen[居民/家属] -->|拨打120| CTI[120 CTI与录音]
  Citizen -->|位置/文字/健康摘要| Assist[居民辅助呼救端]
  CTI --> Command[急救中心指挥调度]
  Assist --> Command
  Command --> GIS[GIS/运营商定位]
  Command --> Ambulance[救护车移动急救端]
  Ambulance --> Device[监护仪/除颤仪/心电]
  Ambulance --> Command
  Ambulance --> Collab[院前院内协同平台]
  Command --> Collab
  Collab --> Hospital[医院急诊协同端]
  Hospital --> HIS[HIS/EMR/LIS/PACS]
  Collab --> RHIP[区域全民健康信息平台]
  Collab --> Emergency[110/119/122/应急指挥]
```

## 6. 呼救与调度泳道

```mermaid
sequenceDiagram
  participant C as 居民/家属
  participant T as 120坐席
  participant D as 调度员
  participant A as 救护车
  participant H as 接诊医院
  C->>T: 拨打120
  C-->>T: 辅助提交位置/症状/健康摘要
  T->>T: 核实地址、人数、主诉和现场风险
  T->>D: 创建已受理事件
  D->>D: 结合距离、能力和车辆状态推荐
  D->>A: 人工确认派车指令
  A-->>D: 接令回执并出发
  A-->>D: 到场/接触患者/转运节点
  D->>H: 发送院前预告
  H-->>D: 接收确认与绿色通道
```

## 9. 患者身份归并流程

```mermaid
flowchart TD
  Start[现场接触患者] --> Known{身份是否明确}
  Known -->|否| Temp[创建院前临时患者号]
  Known -->|是| MPI[查询居民主索引]
  MPI --> Match{唯一匹配}
  Match -->|是| Link[关联居民主索引]
  Match -->|否| Temp
  Temp --> Hospital[医院急诊预建档]
  Link --> Hospital
  Hospital --> Verify[证件/家属/院内信息核验]
  Verify --> Merge{可以安全归并}
  Merge -->|是| Commit[生成临时号到院内就诊号映射]
  Merge -->|否| Review[进入人工身份复核队列]
  Commit --> Audit[保留归并版本和撤销审计]
  Review --> Audit
```

## 10. 弱网与故障降级流程

```mermaid
flowchart TD
  Request[关键业务操作] --> Online{主链可用}
  Online -->|是| Send[实时发送并等待回执]
  Send --> Ack{按时回执}
  Ack -->|是| Done[记录成功]
  Ack -->|否| Retry[幂等重试与告警]
  Online -->|否| Local[本地加密缓存]
  Local --> Fallback[电话/无线语音/短信/纸质交接降级]
  Retry --> Queue[可靠消息队列]
  Fallback --> Queue
  Queue --> Recover{链路恢复}
  Recover --> Replay[按幂等键补传]
  Replay --> Reconcile[人工/自动对账]
  Reconcile --> Done
```

## 11. 数据安全与紧急访问流程

```mermaid
flowchart TD
  Access[访问敏感急救数据] --> Auth[身份认证与终端校验]
  Auth --> Authorized{岗位和任务授权}
  Authorized -->|是| Minimum[按最小必要字段访问]
  Authorized -->|否| Emergency{是否抢救生命紧急例外}
  Emergency -->|否| Deny[拒绝并记录安全事件]
  Emergency -->|是| Reason[填写理由与范围]
  Reason --> BreakGlass[紧急访问]
  Minimum --> Audit[全程审计]
  BreakGlass --> Audit
  Audit --> Review[事后复核与异常检测]
```

## 12. 上线与切换流程

```mermaid
flowchart LR
  Dev[功能开发完成] --> Gate[专项测试与急救门禁]
  Gate --> Joint[120/运营商/车辆/医院联合联调]
  Joint --> Drill[断网、CTI故障、接口积压和灾备演练]
  Drill --> Security[等保/个保/密码验收]
  Security --> Pilot[小范围试运行]
  Pilot --> Signoff{现场证据全部签署}
  Signoff -->|否| Fix[整改并重新验收]
  Fix --> Joint
  Signoff -->|是| Cutover[正式切换]
  Cutover --> Observe[上线观察与每日复盘]
  Observe --> Stable[稳定运行]
```

## 13. 监控告警链路

```mermaid
flowchart LR
  Metrics[API/队列/设备/数据库指标] --> Observe[可观测平台]
  Logs[业务与安全日志] --> Observe
  Traces[端到端链路追踪] --> Observe
  Observe --> Rules[急救SLO与安全规则]
  Rules --> Alert[分级告警]

  Duty --> Incident[事件工单]
  Incident --> Evidence[处置证据包]
  Evidence --> Review[复盘与规则改进]
```
