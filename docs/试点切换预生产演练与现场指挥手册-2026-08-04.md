# 试点切换预生产演练与现场指挥手册

## 1. 安全边界

本手册和配套程序只校验元数据、签名、时间窗、回滚耗时及职责到位情况，不执行部署、数据库写入、流量切换或回滚。生产切换必须由现场指挥长在真实环境审批完成后人工发令。任一检查缺失、账本链损坏、公钥无效、签名失败、证据过期/撤销或演练超过 24 小时，结论均为 `NO-GO`。

## 2. 值守席位

| 席位 | 必须到场 | 职责与停止权 |
| --- | --- | --- |
| 发布指挥长 | 是 | 宣布检查点、`HOLD`、切换和回滚口令；承担最终指挥责任 |
| 业务负责人 | 是 | 验证核心业务闭环；业务异常时可要求 `HOLD` |
| 平台运维 | 是 | 执行现场批准的操作并复诵回滚口令 |
| 安全合规 | 是 | 监控安全告警；严重信号可直接要求 `HOLD` |
| 数据平台 | 是 | 验证一致性、积压和对账；不一致可要求 `HOLD` |
| 机构协调员 | 是 | 协调试点机构窗口、终端与支持团队 |
| 独立观察员 | 是 | 记录时间、证据引用、口令复诵和决策，不执行操作 |

任何席位缺席或代理关系未留存受控证据时不得开始。

## 3. 预生产演练

演练必须绑定同一 `releaseId` 和不可变包 `packageFingerprint`，并在授权账本追加 `rehearsal-recorded` 事件。以下六个检查点必须全部通过：

1. `freeze-writes`：验证冻结边界和积压观测。
2. `snapshot`：验证快照引用、摘要和恢复可用性。
3. `switch-read`：验证只读切换及回退边界。
4. `verify-business-loop`：验证关键业务闭环。
5. `rollback`：完整执行预生产回滚并计时。
6. `post-rollback-verify`：验证回滚后一致性、服务和监控。

实际回滚分钟数必须小于等于批准上限。演练协调员用注册的 Ed25519 身份密钥签署规范化元数据；私钥不得进入仓库、账本或注册表。

```powershell
npm run platform:cutover-authorization -- record-rehearsal --ledger=<绝对账本路径> --input=<绝对演练记录路径>
npm run platform:cutover-authorization -- status --ledger=<绝对账本路径> --package=<绝对发布包路径> --trust-registry=<绝对公钥注册表路径>
npm run platform:cutover-health -- --ledger=<绝对账本路径> --package=<绝对发布包路径> --trust-registry=<绝对公钥注册表路径>
```

## 4. 现场时间线

| 时间 | 检查点 |
| --- | --- |
| T-60 分钟 | 建立指挥频道，逐席点名，确认记录员和替补关系 |
| T-30 分钟 | 核验账本链、公钥、签名、证据、批准、演练新鲜度和监控路由 |
| T-10 分钟 | 宣布最终冻结窗口；逐席给出 GO/NO-GO |
| T0 | 指挥长依据现场批准人工发出切换口令 |
| T+15 分钟 | 核验业务、数据、积压、安全和机构反馈 |
| T+60 分钟 | 决定结束加强观察、延长观察或回滚 |
| T+1 天 | 完成复盘、证据归档和遗留项责任确认 |

## 5. 回滚口令和触发条件

标准口令为 `ROLLBACK PILOT <release-id>`。指挥长发令，平台运维必须完整复诵，独立观察员确认 release ID 和时间；未完成三方闭环不得将口令视为已确认。

出现以下任一情况立即 `HOLD`，并在回滚时间预算耗尽前执行现场批准的回滚程序：

- 数据一致性校验失败；
- 关键业务闭环失败；
- 严重安全信号；
- 监控或告警路由不可用；
- 回滚剩余预算不足；
- 任一停止权席位提出 `HOLD`。

配套 `plan` 命令只生成口令模板与职责，不执行口令：

```powershell
npm run platform:cutover-command-plan -- --release-id=<release-id> --package-fingerprint=sha256:<fingerprint>
```

## 6. T+1 观察

T+1 小时保持加强观察，T+1 天完成正式复盘。观察至少覆盖：

- 业务成功率、错误率和关键旅程；
- outbox 积压、消费延迟、重放和对账；
- 数据一致性、迟到数据和人工修正；
- 安全告警、异常访问和身份事件；
- 试点机构反馈、支持工单和影响范围；
- 证据过期、撤销、公钥有效期、签名状态、账本链和演练新鲜度。

`GET /api/production-adapters/pilot-cutover/health` 为 commission 角色提供只读健康信号，返回 `healthy`、`warning` 或 `blocked`。该接口始终返回 `cutoverExecutionAuthorized: false` 和 `productionReady: false`。
