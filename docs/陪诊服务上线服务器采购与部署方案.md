# 陪诊服务上线服务器采购与部署方案

## 是否需要单独服务器

陪诊模块不建议作为第一阶段单独购买服务器。当前系统是统一平台架构，`escort.html`、居民端陪诊预约和 `/api/escort-services/*` 都复用 `server.js`、统一登录、消息、审计、居民家庭关系、HIS 交接和发布门禁；正式上线需要的是一套能运行 Node API 的后端环境，而不是只托管静态 HTML。

建议按上线阶段选择：

| 阶段 | 服务器策略 | 适用场景 |
| --- | --- | --- |
| 试点演示 | 与慢病平台共用 1 台云服务器 | 少量居民、机构端演示、陪诊流程验证 |
| 受控试点 | 1 台应用服务器 + 托管数据库 + 对象存储 | 有真实居民预约、短信、审计和医院接口联调 |
| 正式生产 | 2 台应用服务器 + 负载均衡 + 托管数据库 + 对象存储 + 日志/SIEM | 多机构上线、需要高可用、审计保全和灾备 |
| 独立部署 | 单独应用服务器或容器服务 | 陪诊服务由独立单位运维、单独域名、单独 SLA 或安全隔离要求 |

## 推荐采购清单

| 资源 | 试点最低配置 | 正式生产建议 |
| --- | --- | --- |
| 云服务器 | 2 vCPU / 4 GiB / 80 GiB SSD，Linux | 至少 2 台 2 vCPU / 4 GiB 起步，跨可用区或可快速扩容 |
| 数据库 | SQLite 仅限试点或演示 | 托管 PostgreSQL/MySQL，开启自动备份和恢复演练 |
| 文件存储 | 本机磁盘临时存放 | 对象存储，用于合同、保险、授权和验收附件 |
| 域名与 HTTPS | 备案域名 + TLS 证书 | 正式域名、HTTPS、隐私协议 URL、移动端入口 |
| 网络安全 | 安全组开放 80/443/22，后台仅内网或 VPN | WAF、堡垒机、最小开放端口、医院专线/VPN |
| 监控审计 | 服务器监控 + `AUDIT_EXPORT_PATH` | 日志归档、SIEM endpoint、告警联系人和值守表 |

## 购买步骤

1. 选云厂商和地域：优先选择医院、社区和运维团队网络访问延迟低、备案和等保材料方便的地域。
2. 购买 Linux 云服务器：选择包年包月或按量付费，试点可从 2 vCPU / 4 GiB 起步；生产建议先按容量评估再扩容。
3. 创建 VPC、子网和安全组：公网仅开放 80/443；SSH 22 端口限制为运维固定出口 IP；医院接口尽量走内网、专线或 VPN。
4. 购买并绑定域名：国内公网访问需要完成 ICP 备案；移动端、小程序和 PWA 入口需要 HTTPS。
5. 准备数据库和备份：试点可用 `DATA_DIR` 指向独立数据目录；生产应迁移到托管数据库，并完成备份/恢复演练。
6. 准备短信、统一身份和医院接口：配置 `SMS_GATEWAY_URL`、`OIDC_*`、医院 `hospitalCode`、科室/医生字典和回执字段。
7. 部署 Node 服务：安装 Node.js，拉取代码，执行 `npm ci`，配置 `.env`，用进程管理器运行 `node server.js`。
8. 配置反向代理：用 Nginx 或云负载均衡把 HTTPS 请求转发到 `PORT` 指定的 Node 服务。
9. 验证上线：执行 `npm.cmd run check`、`npm.cmd test`、`npm.cmd run escort:readiness`、`npm.cmd run release:report`、`npm.cmd run launch:smoke -- --base-url=https://your-domain`。

## 关键环境变量

```text
PORT=5173
NODE_ENV=production
DATA_DIR=/var/lib/chronic-care-platform
SESSION_SECRETS=replace-with-long-random-secret
INTEGRATION_GATEWAY_SECRET=replace-with-integration-secret
OIDC_ISSUER_URL=https://identity.example.gov.cn/real-issuer
OIDC_CLIENT_ID=replace-with-oidc-client-id
OIDC_CLIENT_SECRET=replace-with-oidc-client-secret
SMS_GATEWAY_URL=https://sms.example.gov.cn/real-gateway
AUDIT_EXPORT_PATH=/var/log/chronic-care-platform/audit
SIEM_ENDPOINT=https://siem.example.gov.cn/ingest
```

## 上线前验收

| 验收项 | 必须证据 |
| --- | --- |
| 服务器 | 云服务器实例、VPC、安全组、SSH 白名单、系统补丁记录 |
| 域名 HTTPS | ICP 备案、TLS 证书、HTTPS 访问截图、隐私协议 URL |
| 应用服务 | `node server.js` 运行、`/api/health` 通过、反向代理配置 |
| 数据与附件 | 数据目录或托管数据库、备份策略、恢复演练记录、对象存储桶 |
| 陪诊接口 | HIS/导诊台联调记录、医院回执字段、异常退回补证流程 |
| 消息审计 | 短信模板、消息通道、审计归档路径、SIEM endpoint、告警联系人 |
