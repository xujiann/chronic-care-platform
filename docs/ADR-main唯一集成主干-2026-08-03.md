# ADR：main 作为唯一集成主干

状态：已采纳  
日期：2026-08-03

## 决策

`main` 同时承担唯一集成线、发布源和默认分支。所有
`process/tNN-<topic>-YYYYMMDD` 分支通过拉取请求进入 `main`，发布使用不可变标签、构建产物和环境审批表达，不再维护长期漂移的第二集成分支。

## 门禁

- `main` 禁止直接推送、强推和删除；
- 必须通过 `complete-unit-test` 与 `test`；
- 要求线性历史和已解决讨论；
- 单维护者阶段不要求无法完成的自批准；增加第二名合格维护者后恢复一次批准和 CODEOWNER 审核；
- 生产 Go/No-Go 始终依赖真实环境、外部依赖和签名站点证据。

## CI 触发

功能分支只运行拉取请求检查，不再同时运行同一提交的 `push` 检查。
`push` 全量检查仅对合入后的 `main` 运行。这消除重复计算，也使合入前门禁与合入后主干验证职责清晰。

## 迁移

旧的 `codex/governance-integration-20260803` 仅在本次迁移完成前保留。
其最终绿色提交同步到 `main` 后删除；滚动过程基线标签移动到最终
`main` 提交。
