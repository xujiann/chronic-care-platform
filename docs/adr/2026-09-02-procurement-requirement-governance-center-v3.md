# ADR：招标需求治理中心完整闭环

- 状态：Accepted
- 日期：2026-09-02
- 范围：通用卫生健康信息平台

## Problem

离线受控导入、来源修订、人工复核和能力差距分析已经存在，但脱敏导入文件尚未进入运行时目录；已采纳需求也没有产品规划、开发建议、交付证据与导出闭环。平台需要持续接纳不同地区、不同批次的招标需求，同时避免保存或传播 PDF、文件路径、原文和地域机构信息。

## Options

1. 每次导入后人工修改仓库静态配置并重新发布。
2. 将 PDF 上传到浏览器或服务端后在线解析。
3. 保留离线检查与提取，在平台中只登记脱敏批次，并以独立聚合管理复核、规划、交付证据和安全导出。

## Advantages

选择方案 3。它让未来批次经受控登记直接进入需求池，同时继续隔离外部文档。复核结论绑定来源修订、语义摘要和能力注册表；证据变化会触发重新复核。已采纳需求可以形成确定性的开发建议、版本计划、实施状态和三类仓库证据，并要求提交人与核验人相互独立。

## Disadvantages

平台只接收离线工具生成的脱敏 JSON，不能直接替代 OCR、恶意文件扫描或人工语义校验。仓库证据核验也不代表现场联调、采购验收或生产放行。独立核验需要另一名具备授权的人员登录操作。

## Migration cost

新增目录登记与交付治理两个状态集合、两个写接口、三类证据状态、人工交付验收、独立工作台和安全导出。既有复核接口保持兼容；计划绑定当前复核证据，绑定失效后仍以只读失效计划保留，但不得继续操作或静默继承旧证据。验收支持申请、独立人工验收、退回整改和证据变化后的重新提交，且始终不构成现场或生产授权。

## Risk

主要风险是伪造脱敏文件、重复登记、并发覆盖、旧结论错误继承、证据自审和导出泄露。控制措施包括严格字段白名单、重新验证有效目录、幂等键、期望版本、一次状态与审计写入、精确回放、证据指纹绑定、独立核验和逐字段导出。外部扫描、真实机构联调、备份恢复与生产签批仍是外部门禁。

## Recommendation

以“离线受控导入 → 脱敏批次登记 → 当前修订候选 → 人工复核 → 产品规划 → 确定性开发建议 → 实施 → 三类仓库证据 → 独立核验 → 安全台账导出”为标准闭环。所有运行时视图、回执和导出始终保持 `productionReady=false`；生产状态保持 NO-GO，直至另行完成现场证据和正式授权。
