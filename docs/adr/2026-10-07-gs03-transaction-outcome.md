# GS03 非生产事务提交结果判定

- 状态：Accepted
- 有效范围：仅下述非生产组件。
- 日期：2026-10-07；决策 ADR-GS03-OUTCOME-001；任务 GOV-032、OPS-052。
- 依据：用户确认推荐路线、明确“由我统一协调，专业事项另行签署”，并要求继续开发。批准仅覆盖未接线组件开发测试，不代表专业事项签署、父 CALLBACK/STORAGE/S2 接受、推送合并或上线。

## Problem

已有隔离实验在 COMMIT 异常后保守返回 unknown。共同事务实现还需要可复用的执行阶段与结果判定，避免提交已完成但响应异常时错误宣布回滚并重复业务。组件不能根据普通异常文本推断数据库事实。

## Options

1. 复制实验中的 try/catch 到业务入口：判定易漂移。
2. 独立未接线的异步阶段执行器：本片采用，真实事务由可信适配端口负责。
3. 本轮接入完整回调、迁移和全部写者：专业决策和正式接口尚未具备，不实施。

## Contract

模块 src/platform/storage/gs03-transaction-outcome.js，输入 environment 必须为 development 或 test。显式可信端口提供 begin、apply、verify、commit、rollback；不接受 dbPath，不打开数据库、不读环境变量、不调用网络或 server。端口属于同一进程内受信任实现，配置不能将任意外部请求转换为端口；环境参数不是生产安全隔离证明。

begin 明确返回 true 才进入 apply；apply 仅返回 first 或 replay。verify 必须在 commit 前返回 true，代表适配方完成本次提交前复核，组件本身不证明授权。commit 必须明确返回 true 才报告 confirmed-first 或 confirmed-replay。其他返回或异常全部失败关闭。

一旦调用 commit，任意异常或非 true 结果均返回 unknown；即使后续 rollback 成功也不得改为 rolled-back。commit 之前的异常，仅当 rollback 明确返回 true 才报告 rolled-back，否则 unknown。begin 调用异常亦由适配方清理其可能启动的事务；端口必须独占本次事务，禁止回滚其他调用的事务。相同端口对象并发或重入拒绝，unknown后同一对象永久拒绝再次执行；重新构造对象不是恢复证明，仍需调用方对账并解除数据库层风险后另行接入。适配方负责跨对象/跨进程的排他性。

输出只有固定 status、phase 和 productionReady=false，不传回业务对象、凭据、路径或异常。未知结果不触发重试、核验、补审计或换键。恢复需后续在同一权威、当前授权和共同提交保护下以原 key 核验；本组件不实现恢复。已确认结果发送给客户端失败也不能倒推回滚。

## Advantages and Disadvantages

阶段、错误和输出稳定；异步端口可用于后续候选适配。端口返回 true 是受信任适配器的契约，不是证据验真；本模块不保证物理事务、幂等、授权或外部 scope，不是完整共同事务端口。

## Migration cost

无 schema、注册表、数据集合、HTTP、默认启动或依赖变更。不导入旧实验 helper，不改既有实验和 v1 业务。移除未接线模块及专项即可回退，不修改数据库。

## Risk

专业事项仍待签署；留存/恢复数值无默认值。父 Proposed 不变，GS03整体未完成，生产六域 NO-GO。非生产组件不得接现库或装配到应用；真实生产适配器需另立准入。
