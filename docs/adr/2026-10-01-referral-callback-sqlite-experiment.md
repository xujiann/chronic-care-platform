# ADR-GS03-EXPERIMENT-001：隔离 SQLite 回调原子性实验

- 状态：Accepted
- 日期：2026-10-01
- 批准依据：用户在明确列出的隔离实验范围后回复“批准”；仅批准本决策的实验范围。
- Owner：T08 负责实验 receipt 与测试交付；T00 审定物理事务实验合同和集成治理。既有居民授权、会诊、消息及审计的正式数据 Owner 不变。
- 任务：TEST-026；GOV-027 继续单写设计与实验准入治理。

## Problem

现有三条回调未证明确切授权、回执和业务副作用共享线性化点。正式协议 ADR-GS03-CALLBACK-001 与存储 ADR-GS03-STORAGE-001 仍为 Proposed，真实调用方与生产留存政策尚未决定。现在需要用可复现的合成实验检验 SQLite 同库方案的可行性，而不是接入现有应用或宣称已修复。

## Options

1. 等待全部正式协议、存储与迁移决策后再试验，反馈较晚。
2. 批准独立、无 HTTP 的一次性合成 SQLite 实验，提前检验唯一性、原子性和恢复语义。本次仅选择此项。
3. 直接修改现有回调或创建正式 repository，需要尚未取得的合同、Owner 与迁移批准，本次不采用。

## Advantages

使用真实 SQLite 文件、双连接及子进程观察提交和崩溃，不以 mock 模拟数据库原子性。所有代码位于测试目录，默认应用不加载；实验失败不会改变既有业务或回执。

## Disadvantages

实验使用受信的测试主体和合成授权，不能证明真实 provider、跨库身份目录、现网写入口或正式 v15 审计 hook 已正确接线。即使通过，也不授权生产 SQLite 主权威或 PostgreSQL 切换。

## Migration cost

只允许在本实验新建的专属临时目录内创建空数据库及临时实验 DDL。初始化不得接受既有陌生数据库；重开必须验证实验标记及身份。不运行平台 migration、不改变 schema head v19、不预占后继版本、不导入 legacy 事件或真实数据。实验库与既有库没有迁移/同步关系。测试结束仅清理自己创建且路径已核实的合成目录；不提供生产清库或降级入口。

## Risk

### 限域合同

- 测试主体由可信测试夹具提供，不能从业务载荷自报；只证明这一输入前提下的本库一致性，不实现认证服务。
- receipt 在实验库中按主体 namespace、合同及版本、幂等 key 唯一，绑定目标案例、确切授权 ID 与固定版本的确定性意图摘要。三种实验合同只映射反馈、排期、报告；不同主体的相同 key 独立，不宣称跨主体逻辑事件去重。
- 在同一连接取得 `BEGIN IMMEDIATE` 写事务后读取案例、绑定授权和 receipt。首次及重放均检查居民、用途、目标机构、有效状态及受控服务端时钟的到期条件；首次提交前再次检查到期。缺绑定拒绝，不寻找其他有效授权替代。撤权入口使用同一数据库写事务；回调先提交则保留历史，撤权先提交则首次/重放均拒绝。
- 首次在一个事务内提交 receipt、案例、报告所需档案、两条应用内消息、安全/访问审计及模拟 append-only source。精确重放不追加这些副作用；同 namespace 下异目标、异授权或异意图冲突，不泄漏原 receipt。实验 source 不等于真实平台 v15 hook。
- 区分已确认提交、已证明回滚、提交后响应丢失与结果未知。事务中故障只有确认回滚才报零写；COMMIT 结果未知不可冒充回滚，不得换 key。重开后在当前授权下用同 key 核验；撤权后不返回旧回执。故障注入仅在测试接口，不接服务。
- receipt 在实验数据库存续期间不可逐条更新、删除、过期清理或复用 key；超过 200 条仍须可重放。不回填旧事件摘要，不填写生产保留天数。销毁整个自有合成测试库不是生产保留政策。

### 边界与回滚

SLA 确认、通用 workflow、直接授权/档案修改、grant/revoke/resume、报告归档的 500 条裁剪、整库保存/重置等入口仍可能影响授权或会诊。此清单不是全仓穷尽；本实验不改这些入口，也不声称已排除旁路。现有路径可能继承 collection CAS，但尚未证明业务读取与版本采集属于一致受控快照。

回滚仅撤销测试代码及本轮治理增量，或停止实验并保留失败证据。既有业务、历史审计、旧回调与正式 schema 均不动。不得由通过实验推导 GS-03 已建设或生产准入，六域继续 NO-GO。

## Recommendation

本 Accepted 决策只为 TEST-026 提供限域实施依据，明确作为两份 Proposed ADR“实施前置”的唯一实验例外；不是接受它们的正式协议、存储权威、迁移或 HTTP 接线。它们保持 Proposed，任何正式 repository、现库 DDL、调用方迁移或新 lane 实施仍须另行 Accepted 决策与 PLAN。

### PLAN 与单写者

目标为真实 SQLite 合成实验及故障/并发证据。T08 独立 worktree 基于最新 fetched `origin/main@b37e3ce9`，分支 `process/t08-gs03-sqlite-experiment-20261001`。开发 A 单写 `test/helpers/gs03-sqlite-experiment.js`；开发 B 单写 `test/gs03-sqlite-experiment.test.js` 与 `test/helpers/gs03-sqlite-experiment-child.js`。T00 在原设计分支单写本 ADR、两份父 ADR 的例外说明、索引、生命周期/文档清单、ROADMAP 与六张地图。各开发者不覆盖另一写者，T00 负责唯一集成。

验收：三合同首次/精确重放/异意图/异目标/跨主体；确切授权缺失、错误居民/用途/机构、撤销/到期及提交前到期；真实双连接和多进程的唯一键竞争与撤权排序；逐副作用失败回滚；提交前进程退出、提交后丢响应、未知结果重启核验；receipt 不可变与超过 200 条保留；隔离边界拒绝测试。专项先执行，独立审查通过后冻结提交，再串行运行适用的 18 项平台门禁；失败回到修复与重新审查，不弱化旧测试或复用旧 SHA 的证据。本轮不推送、合并、部署或激活 worker。
