# ADR：标题

- 状态：Proposed
- 日期：YYYY-MM-DD
- Owner：
- 影响范围：

## Problem

当前事实、约束、证据和必须作出的一个决策。

## Options

至少两个真实方案；适用时包含维持现状。

## Advantages

各方案主要收益。

## Disadvantages

各方案代价、限制和长期影响。

## Migration cost

低/中/高/极高，并解释人力、数据、兼容、部署和运维成本。

## Risk

安全、数据、兼容、运行、回滚和延迟决策风险。

## Recommendation

推荐方案、理由、批准前置条件、非目标、迁移和回滚边界。
