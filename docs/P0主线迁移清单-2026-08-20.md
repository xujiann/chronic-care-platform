## 兼容、迁移与回滚

- API 路径、角色、成功响应和 `/api/audit/verify` 的 HTTP 200 业务结果保持兼容。
- 组合根增加一个显式 `audit-chain-v2` 安全端口依赖（require 预算 126→127），同时删除两份内联验证实现；该预算变化由架构门禁锁定，不代表允许继续增加组合根业务依赖。
- `PUT /api/state` 的审计数组从“兼容写入并可能重封”收紧为服务端管理字段。客户端应省略 `securityEvents` / `dataAccessLogs`；若提交则必须与当前服务端值完全一致。
- 乐观版本冲突先返回原有 `409 STORAGE_CONFLICT`。审计字段修改返回 `400 AUDIT_TRAIL_WRITE_REJECTED`；现有链异常返回 `409 AUDIT_TRAIL_INTEGRITY_FAILED`。
- 当前跟踪种子不需要迁移。外部历史链必须先只读 preflight、封存原始摘要并取得独立审批；禁止请求路径重封。
- 回滚按独立提交反向回退：公卫去重、审计 v2、授权矩阵互不依赖数据回滚。回退审计 v2 会恢复已知 SEC-003 风险，只允许限时应急且不得据此宣布生产就绪。
