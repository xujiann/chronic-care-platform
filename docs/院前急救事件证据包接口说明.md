# 院前急救事件证据包接口说明

`GET /api/emergency/events/:id/evidence-package` 用于按单输出院前急救任务的运行证据包。

证据包覆盖：

- 呼叫受理：事件号、来源、来电人、地址、主诉和受理时间。
- 调度任务：任务号、救护车、派车时间和预计到达时间。
- 车辆轨迹：出发、到达现场、接触患者、开始转运和到院节点。
- 院前病历：初步诊断、生命体征和现场处置。
- 医院接诊：接诊医院、绿色通道、响应时间和接诊意见。
- 电子交接：院内就诊号、院前签署人、院方签署人和 `WS/T 621-2018` 标准标记。
- 操作审计：状态时间线和事件审计记录。

证据包可以在任务未完成时查询，并通过 `completeness.missing` 明确显示缺失章节；它属于运行证据，不替代生产现场签署、外部接口验收或正式切换审批。
