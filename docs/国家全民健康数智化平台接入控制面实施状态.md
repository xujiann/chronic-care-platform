# 国家全民健康数智化平台接入控制面实施状态

更新时间：2026-07-24

## 本轮交付

本轮将工程从“单一区域业务平台”向“国家能力底座、分级节点、机构按需接入”推进，新增国家级接入控制面。该控制面不集中保存全国原始业务数据，负责管理元数据、节点、机构、服务目录、订阅关系和认证状态。

总体模型为“1+N+M”：

- `1`：国家全民健康数智化能力中心；
- `N`：省级、区域或行业节点；
- `M`：医院、基层、检验、影像、公卫、医保、医药、养老和科研等接入机构。

## 已实现能力

### 节点注册与认证

- 支持国家、省级、区域和行业节点类型；
- 新节点默认进入 `submitted`；
- 管理方按 `verify → activate` 完成认证；
- 仅活动节点可以承载新机构；
- 节点编码和行政区划编码执行统一校验。

### 机构注册与租户隔离

- 机构同时维护本地机构编码、国家机构编码、节点、行政区划和租户标识；
- 支持九类机构；
- 新机构默认进入 `submitted`，经核验后激活；
- 机构账户只能查询和操作自身 `orgCode` 范围；
- 管理账户可查看全国节点、机构、订阅和审计情况。

### 六类服务包

1. 机构注册与基础身份包；
2. 检验检查跨省共享包；
3. 居民电子健康档案包；
4. 公共卫生联动包；
5. 医疗医保医药协同包；
6. 可信数据与人工智能包。

服务包按需订阅。依赖基础身份能力的服务，在基础包未激活时禁止申请。

### 订阅生命周期

订阅状态为：

`requested → approved → active → suspended/cancelled`

机构可申请或取消自身订阅，国家平台主管负责审批、激活和暂停。

### 机构自助接入门户

`national-access.html` 已提供国家管理和机构两类视图：

- 国家管理人员可注册节点、注册机构、核验激活、记录节点健康、管理服务订阅、签发试点证书和治理标准扩展；
- 机构人员只能查看本机构租户、订阅和相关路由记录；
- 机构可在线申请服务包、登记和撤销本机构来源授权、创建和轮换自身开发者密钥，并验证本机构作为来源方的跨省路由；
- 页面展示“1+N+M”架构、六类服务目录、节点健康、机构租户、订阅生命周期、路由记录、LIS/PACS路由信封、SLA告警和标准冲突；
- 页面提供按机构订阅动态裁剪的机器可读合同和可下载 JavaScript SDK；
- 页面提供HIS、EMR、LIS、PACS/RIS、电子健康档案、公卫、医保和医药适配器登记、合同测试及回调回执工作台；
- 开发者密钥明文只在创建或轮换成功时显示一次，常规总览接口不会返回明文或不可逆摘要。

### 节点健康与跨省路由

- 节点健康支持 `healthy`、`degraded`、`unavailable` 三种状态；
- 路由规划前校验来源机构、目标机构、节点状态和双方服务包订阅；
- 不可用主节点优先切换到同省已激活、健康且具备临床路由能力的灾备节点；无可用灾备时阻断路由；
- 降级节点生成降级路由，故障转移路由标记主节点和实际承载节点；
- 跨节点路径按“来源节点 → 国家能力中心 → 目标节点”生成；
- 路由记录只保留机构、节点、服务包、用途和令牌化居民引用等元数据。

### 居民授权、安全凭证与交换合同

- 授权记录只保存脱敏居民引用、来源/目标机构、服务包、合同、用途、法律依据、有效期和授权原文SHA-256摘要；
- 授权原文不进入国家控制面，且授权支持来源机构或国家管理方撤销；
- 证书主体可为分级节点或接入机构，控制面只登记公钥指纹，不保存私钥；
- 沙箱和试点证书支持签发、到期和吊销生命周期；
- 开发者密钥权限必须属于机构已激活服务包，控制面仅保存SHA-256摘要；
- 路由信封逐项校验国家交换合同、业务载荷摘要、授权状态与有效期，以及来源、目标、服务包、合同和用途的授权范围；
- 路由信封明确 `payloadIncluded=false`，不把检验报告、影像文件或电子病历正文复制到国家控制面。

### SLA与标准治理

- 运行评估覆盖节点可用性、节点延迟、探测新鲜度、路由延迟和故障转移次数；
- 同一告警使用稳定告警键归并，条件消失后下一次评估自动标记恢复；
- 国家标准发布当前活动版本和兼容策略；
- 属地扩展必须基于当前国家版本，并使用节点编码命名空间；
- 版本或命名空间冲突的扩展不能审批，只能整改后重新登记或驳回。

### 开发者沙箱、配额与接入认证

- `national-access-developer-sdk.js` 提供浏览器/Node.js通用客户端、幂等键和SHA-256辅助方法，只白名单发送调用元数据；
- `GET /api/national-access/sdk/manifest` 按机构已激活服务包发布可用合同、请求模式、授权策略、配额和生产阻断声明；
- 开发者通过一次性密钥访问沙箱或试点调用入口，服务端只比较SHA-256摘要，不保存或回显密钥明文；
- 每次调用校验密钥状态、有效期、机构服务订阅、服务包权限和国家交换合同；
- 调用只提交合同、幂等键和业务载荷摘要，控制面明确 `payloadIncluded=false`；
- 相同密钥和幂等键重复提交时返回原回执，不新增调用记录、不重复计量；
- 沙箱默认每分钟60次、每日1000次，试点默认每分钟300次、每日10000次；
- 安全生命周期评估自动识别30天内到期和已到期凭证，已到期凭证转为 `expired` 并阻断调用；
- 机构接入认证报告检查机构、节点、服务包、证书、密钥和安全告警，输出通过、有条件通过或未通过；
- 接入认证报告始终保持 `productionReady=false`，不替代真实网络、安全、容灾和多方签字验收。

### 现有系统适配器与合同联调

- 机构按系统、环境和国家合同登记适配器，只保存端点配置引用、证书引用和配置摘要，不接收接口密钥；
- 适配器合同必须属于机构已激活服务包，并符合HIS、EMR、LIS、PACS/RIS等系统类型的合同边界；
- 每个合同执行模式、签名、幂等、重试、审计和最小必要六项一致性检查，测试证据只登记SHA-256摘要；
- 机构可执行测试和暂停自身适配器，但不能自行认证；国家管理方只有在全部声明合同存在通过记录后才能认证；
- 国家合同目录新增患者主索引、电子健康档案索引和公共卫生事件合同，为后续居民本人查询与公卫联动保留统一接入路径。

### 回调订阅与回执

- 机构可订阅路由信封准备、授权撤销和合同测试完成事件；
- 控制面生成事件摘要、稳定幂等键和签名元数据，不在回调任务中包含临床业务载荷；
- 接收方提交回执摘要和回执编码后，投递任务进入已回执状态并写入审计；
- 当前回调只形成沙箱/试点任务和回执闭环，不主动访问生产端点。

## 数据边界

- 国家中心集中管理机构、节点、服务和标准元数据；
- 检验报告、医学影像和健康档案等业务数据继续保留在来源机构或合规节点；
- 跨省业务由国家目录和分级节点寻址，按授权返回最小必要结果；
- 当前实现不替代HIS、EMR、LIS、PACS/RIS、医保和公卫核心系统。

## 生产上线边界

平台软件能力已形成可运行闭环，但生产环境继续保持阻断，且代码不会伪造下列外部事实：

1. 正式CA签发的国密或等保要求证书、HSM/KMS托管和密钥仪式记录；
2. 真实省级节点、机构前置机、专网/VPN、DNS、时间同步和灾备资源；
3. HIS、EMR、LIS、PACS/RIS、公卫、医保和药品系统真实合同映射；
4. 性能、渗透、商用密码、等保、数据安全和个人信息保护测评证据；
5. 跨省互认规则、数据授权、责任边界及国家—省—机构多方签字验收。

上述证据齐备前，只允许使用沙箱或试点环境，不签发生产证书和生产开发者密钥。
