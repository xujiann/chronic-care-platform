# 公共卫生五件套功能说明与验收

## 1. 范围

本增量在现有公共卫生标准矩阵、机构责任、事件处置、数据交换和上线证据基础上，增加五件套指挥能力：

1. 多点触发监测预警
2. GIS公共卫生一张图
3. AI流调研判助手
4. 应急指挥与资源调度
5. 数据质量与证据链驾驶舱

五项能力共享 `publicHealthSignals`、`publicHealthAlerts`、`publicHealthCommandTasks`、`publicHealthResources`、`publicHealthAiReviews` 和 `publicHealthEvidenceRecords`，形成“信号—预警—研判—任务—资源—证据—复盘”链路。

## 2. 运行入口

- 页面：`public-health-highlights.html`
- API：`GET /api/public-health/highlights`。city/health-admin 保留合法全平台业务视图；district 仅返回自身组织和服务端 `publicHealthHospitalCodes` allowlist 内的 signal，alert 仅在全部关联 signal 均可见时返回。所有角色响应均删除服务端幂等元数据 `commandKeyHash`、`requestDigest`。
- 信号接入：`POST /api/public-health/highlights/signals`
- 预警动作：`POST /api/public-health/highlights/alerts/:id/actions`
- 任务动作：`POST /api/public-health/highlights/command-tasks/:id/actions`
- AI复核：`POST /api/public-health/highlights/ai-reviews/:id/actions`
- 证据动作：`POST /api/public-health/highlights/evidence/:id/actions`
- 就绪检查：`npm run public-health:highlights:readiness`

## 3. 功能闭环

### 3.1 多点触发监测预警

规则包含来源类型、指标、阈值、时间窗口、严重级别和动作模板。当前演示种子覆盖临床症候群、实验室、药店、学校/养老和公众上报五类来源。信号保留来源系统、观察时间、机构、区域、质量状态和证据引用。

### 3.2 GIS公共卫生一张图

地图使用区域网格表达信号与预警节点，节点可以下钻到机构、来源、数值、区域和证据引用。正式 GIS 底图接入仍需现场地图服务、坐标标准和机构主数据确认；当前页面明确标注为结构化演示投影。

### 3.3 AI流调研判助手

AI研判记录包含模型版本、置信度、摘要、推理依据、建议动作和证据引用。`humanApprovalRequired=true` 是强制边界，只有人工采纳后才能作为处置参考；系统禁止自动发布疫情信息、替代人工流调结论或自动升级重大事件。

### 3.4 应急指挥与资源调度

预警可以关联任务、责任人、机构、区域、截止时间、必需动作和资源。任务动作支持接单、派发、完成、升级和重开；资源保留容量、可用量、单位、区域和最后更新时间。

### 3.5 数据质量与证据链驾驶舱

每项证据记录关联来源集合、期望数量、已观察数量、状态、责任方和证据字段。驾驶舱展示已记录、已核验、待补证据、质量分数和安全审计事件数量。

## 4. 验收清单

| 验收项 | 通过口径 |
|---|---|
| 五件套能力 | readiness 报告识别 5 项能力 |
| 多源信号 | 至少 5 条规则、6 条信号、4 条活跃预警 |
| 一张图 | 至少 3 个区域、信号节点和预警节点可展示 |
| AI研判 | 每条建议有模型版本、证据引用和人工确认字段 |
| 应急调度 | 至少 4 个任务，均有责任人、时限和资源引用 |
| 资源管理 | 至少 5 项资源可显示容量和可用量 |
| 证据驾驶舱 | 至少 8 条证据记录，状态和来源可追溯 |
| 动作审计 | 信号接入、预警、任务、AI、证据动作写入 `securityEvents` |
| 安全边界 | 非 `commission` 角色获得 401/403，居民数据不进入五件套默认响应 |
| 发布边界 | `functionalState=five-suite-runnable`，`formalGoLiveState=blocked-until-site-evidence-signed` |

## 5. 上线边界

五件套的本地功能和演示数据闭环已具备；正式上线仍需现场完成真实 HIS/EMR/LIS/药店/学校等接口联调、身份和机构主数据、GIS服务、安全测评、监控路由、备份恢复、应急演练、审计归档和多方签字。`formalGoLiveState` 不因演示数据通过而自动转为生产就绪。
