# 血液信息系统召回闭环增量交付说明

## 交付日期

2026-07-12

## 本次完成

本次将“血液召回通知”从血液中心发起扩展为可验收的机构确认闭环：

1. 受影响用血机构只能确认本机构范围内的召回通知。
2. 确认必须使用标准处置字典，并记录处置说明、受影响患者数量和证据引用。
3. 同一机构只能确认一次；相同幂等键重放原响应，不重复生成确认记录。
4. 每次确认更新期望机构数、已确认机构数和待确认机构数。
5. 全部机构确认后进入 `acknowledged`，血液中心通过关闭接口完成 `closed`。
6. 确认和关闭均写入血液审计链，确认同步生成 `recall_acknowledgement` 交换消息。
7. 前端安全闭环页面按机构显示待确认召回，并通过鉴权 API 提交确认。
