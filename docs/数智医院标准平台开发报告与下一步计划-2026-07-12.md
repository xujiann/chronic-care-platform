# 数智医院标准平台开发报告与下一步计划

- 报告日期：2026-07-12
- 开发分支：`codex/merge-chronic-followup-into-platform`
- 当前阶段：MVP 业务能力与生产化基础持续完善，PostgreSQL 已具备迁移制品、事务 outbox 和影子同步能力，主库切换仍处于受控阻断状态
- 生产结论：代码与自动化门禁通过不等于现场生产验收。真实数据库、外部接口、密钥、监控、容量、灾备、安全测评和正式签字完成前，`productionReady` 必须保持为 `false`

## 一、本轮主要开发成果

### 1. PostgreSQL 事务 outbox

- SQLite 存储模型升级至 v8，在业务写事务内只为实际变化的集合写入 `postgres_sync_outbox`，避免业务提交成功但同步事件丢失。
- 每个批次包含批次 ID、源版本、载荷摘要、前序链摘要和当前链摘要，可发现载荷篡改与链路断裂。
- outbox 状态覆盖 `pending`、`retry`、`delivered`、`failed`，并记录尝试次数、下次执行时间、错误摘要和送达时间。
- outbox 可能包含业务数据，运维文档明确其数据目录、备份、访问控制和留存要求必须按生产敏感数据管理。

### 2. PostgreSQL 幂等影子同步

- 新增独立 `postgres:sync-worker`，以 PostgreSQL 事务写入 `runtime_sync_batches` 和 `runtime_collection_state`。
- 批次写入使用唯一批次 ID，重复执行不会重复应用；集合写入使用单调源版本，旧版本不能覆盖新版本。
- worker 支持指数退避、最大尝试次数和终止失败状态；成功与失败均回写 SQLite outbox，返回结果不暴露数据库连接信息。
- 新增加固的 systemd oneshot 与 timer 模板，默认每 15 秒拉取一次，并限制可写目录和进程权限。
- worker 已进入不可变生产部署包，随制品执行 SHA-256 文件验签。

### 3. 健康状态与发布门禁

- `/api/health` 存储元数据新增同步模式、目标角色、待同步、重试、已送达、失败、最早积压时间和最近送达时间。
- 生产数据库 readiness、环境矩阵、生产审计、发布报告、部署检查和 CI 已接入 outbox、worker、TLS 和影子目标边界。
- `POSTGRES_SYNC_MODE=outbox` 时必须配置 PostgreSQL 地址；生产环境要求 `POSTGRES_SSL_MODE=verify-full`。
- `STORAGE_ENGINE=postgres` 仍会显式拒绝启动。当前 PostgreSQL 仅是影子目标，不是生产主读写库。

### 4. PostgreSQL 迁移制品增强

- 迁移 schema 新增 `health_platform.runtime_sync_batches` 与 `health_platform.runtime_collection_state`。
- 清单模式继续保持无业务正文，当前快照汇总 146 个集合、630 条记录和 20 个快照。
- 全量导出仍要求显式确认敏感数据，并强制写入仓库外受控目录；制品不保存数据库用户名、密码或连接串。

## 二、正式生产前已实现的主要标准平台功能

1. 标准治理与评价：六大标准域、自评、校验、整改、证据包和割接审批台账。
2. 数据治理与存储：资产目录、标准字典、血缘、质量规则、SQLite 生产配置、PostgreSQL 迁移制品与影子同步。
3. 接口集成：医院系统、号源、支付、医保、证照和区域交换的签名、幂等、重试、死信与对账基础。
4. 身份安全与审计：多角色会话、数据范围、审计哈希链、附件安全和国密适配中心。
5. 医疗质量与运营：质量安全、危急值、病历抽查、整改闭环、床位、人力、设备和药耗监管。
6. 公共卫生与慢病协同：21 个公共卫生标准域、慢病筛查分层、随访、家医、免疫和传染病直报。
7. 居民连续服务：健康档案、预约挂号、支付退费、护理、陪诊、影像和跨服务待办。
8. 运行保障与发布治理：健康检查、SLO、告警、事件、不可变制品、密钥外置、备份恢复和回滚契约。

## 四、当前生产阻断项

1. PostgreSQL 主读写适配器尚未启用，当前只有全量迁移制品和 SQLite 到 PostgreSQL 的受控影子同步。
2. 尚未完成生产级一致性核对、积压容量压测、故障注入、主库备份恢复和切回演练。
3. OIDC、短信、医院系统、支付、医保、证照、对象存储和 SIEM 仍需真实凭据、白名单和联合测试回执。
4. 生产域名、TLS、网络区划、Vault/KMS、制品仓库、编排平台和现场权限尚未验收。
5. 等保、密评、渗透、隐私影响评估、灾备演练和 go/no-go 正式签字尚未完成。

1. 实现 PostgreSQL 主读适配器与显式切换开关，先支持只读核对，再支持受控主写。
2. 建立 SQLite 与 PostgreSQL 集合级摘要、记录计数、版本和抽样内容的一致性核对任务及告警。
