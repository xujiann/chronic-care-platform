# 药品耗材与合理用药监管平台 开发报告

生成日期：2026-07-08

## 一、建设目标

药品耗材与合理用药监管平台面向卫健委、医保和医疗机构三类协同主体，围绕合理用药、处方审方、固定取药、药品耗材追溯、供应保障、高值耗材线索、医保结算协同和整改闭环，形成可运行、可审计、可纳入发布门禁的监管应用。

本模块不另起平行系统，复用现有慢病平台的居民主索引、固定取药、医保结算、机构监管、接口契约、统一任务动作、审计留痕和多角色页面体系，作为“智慧医院管理线-药品耗材监管”的应用切片。

## 四、已实现功能

### 1. 合理用药与处方审方监管

- 已建立 `rational-medication` 监管边界。
- 监管线索关联居民、固定取药计划、医保结算单和审方状态。
- 支持医保端进行审方/审核动作，形成业务 `auditTrail` 和安全事件留痕。
- 支持结算前补充处方审核意见、用药依据、医保协同状态。

### 2. 固定取药监管

- 已建立 `fixed-pharmacy` 监管边界。
- 复用 `medicationPickups` 中的药品、药房、下次取药日期、医保审核、药房状态。
- 支持居民固定取药计划与医保审核、机构确认、药房状态之间的闭环追踪。

### 3. 供应保障异常预警

- 已建立 `supply-alert` 监管边界。
- 当前示例 `dcs-supply-mp3` 关联 `medicationPickups/mp3` 和 `insuranceClaims/ic2`，表达二甲双胍固定取药低库存预警。
- API 已返回 `summary.supplyAlerts` 和 `supplyAlerts` 列表。
- `drug-consumable:readiness`、`deploy:check`、`release:report` 已将供应保障预警纳入门禁证据。

### 4. 高值耗材线索监管

- 已建立 `consumable-clue` 监管边界。
- 高值耗材线索关联机构监管、医保结算和整改状态。
- 支持机构提交耗材目录版本、整改说明、使用记录、收费项目和 claimId 等证据。

### 5. 药品耗材追溯码证据闭环

- 已落地 `drugTraceabilityPolicySources`，收录国家医保局、国家药监局官方政策来源。
- 已落地 `drugTraceabilityEvidenceRequirements`，覆盖扫码采集、三码映射、扫码失败/无码人工核验、高值耗材目录交叉核验、整改审计五类证据。
- 支持 `/api/drug-consumable-supervision/:id/traceability-evidence` 提交追溯证据。
- API 自动计算 `traceabilityEvidenceCoverage`，前端展示已完成、部分完成和缺失字段。

### 6. 医保结算协同

- 已建立 `insurance-settlement` 监管边界。
- 复用 `insuranceClaims` 与 `insurance-settlement-v1` 接口契约。
- 支持医保端 `insurance-sync` 动作，记录结算批次、医保同步状态和审计事件。
- 角色边界已区分医保经办审核、机构整改和卫健委监管。

### 7. 整改闭环与审计留痕

- 已建立 `remediation-loop` 监管边界。
- 支持机构端整改提交、卫健委/医保端复核、统一任务动作复用。
- 监管动作进入业务 `auditTrail`，安全事件进入 `securityEvents`。
- 审计哈希链支持校验和篡改检测，并对历史编码漂移导致的假阳性进行稳健处理。

### 8. 前端入口

- `insurance.html`：医保端药耗监管面板、追溯政策来源、证据清单、医保同步和审方动作。
- `institution.html`：机构端药耗整改面板、追溯证据上传、整改提交。
- `workbench.html`：管理端药耗监管汇总、政策来源、证据状态、发布证据入口。
- `drug-consumable-about.html`：政策说明、系统边界、角色边界、验收边界和上线准备说明。

## 六、下一步开发计划

### 1. 现场接口联调

- 对接真实 HIS、EMR、药房库存、耗材管理、医保结算和医保回调接口。
- 明确字段版本、接口幂等键、签名方式、失败重试、补偿队列和对账周期。
- 将当前 seed 示例替换为现场联调样例和脱敏回放样例。

### 2. 追溯码实采能力

- 接入扫码枪、扫码服务或院内药房扫码系统。
- 建立追溯码批量上传、扫码失败、无码登记、人工核验、重复销售预警。
- 增加医保编码、商品码、追溯码三码映射版本管理。
- 增加大中小包装级联关系校验和发码机构识别。

### 3. 合理用药规则库

- 建立药品规则版本、规则来源、适用机构、启停状态。
- 扩展禁忌症、重复用药、超剂量、重点监控药品、抗菌药物、长期处方周期等规则。
- 增加机器预警、药师复核、医生确认、医保审核之间的闭环。

### 4. 供应保障管理

- 将单条低库存预警扩展为库存阈值、采购计划、医联体调拨、替代药推荐和固定取药延期通知。
- 对接药房库存和采购系统，形成缺药登记、调拨审批、配送确认、居民通知。
- 形成基层慢病用药目录和长期处方保障指标。

### 5. 高值耗材深度监管

- 对接耗材目录、收费项目、使用记录、批号、手术/病案、医保结算明细。
- 建立高值耗材使用异常、目录版本不一致、收费项目不匹配、重复收费等规则。
- 增加机构说明、医保复核、卫健委监管、整改办结闭环。

### 6. 整改闭环增强

- 增加整改任务分派、责任人、期限、证据上传、复核、退回、办结、逾期升级。
- 建立机构整改完成率、逾期率、重复问题、医保协同处理时效指标。
- 将整改结果纳入机构监管和智慧医院管理总览。

### 7. G 端综合管理汇总

- 向智慧医院管理总览输出药品、耗材、供应、追溯码、医保协同、整改完成率等指标。
- 支持按机构、药品、耗材类别、风险等级、医保状态、整改状态筛选。
- 形成监管态势、风险清单、整改看板和发布验收证据入口。

### 8. 生产上线准备

- 配置真实身份源、生产密钥、审计留存目标、日志导出或 SIEM。
- 完成接口联调签字、医保/机构/卫健委现场验收、监控告警、灾备演练。
- 将 release report 中的生产审计留存 warning 转为通过状态。

## 七、阶段结论

本模块已完成药品、耗材、合理用药、固定取药、供应保障、追溯码证据、医保协同和整改闭环的演示级可运行能力，并已进入自动化 readiness、deploy check 和 release report 证据链。下一阶段重点不再是页面说明，而是对接真实业务系统、扩展规则库、深化追溯码实采和补齐生产上线签字验收材料。
