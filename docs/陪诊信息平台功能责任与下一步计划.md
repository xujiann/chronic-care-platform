# 陪诊信息平台功能责任与下一步计划

| 功能 | 责任部门 | 当前证据 | 下一步计划开发功能 |
| --- | --- | --- | --- |
| 居民端陪诊预约、家庭成员代办、提交前核对 | 老龄健康服务部门、社区卫生服务中心 | 居民端表单、字段必填校验、重复预约拦截 | 接入实名身份、短信网关、电子健康卡和真机消息模板 |
| 服务主体名录、发布状态、价格和应急预案 | 老龄/民政协同服务部门、服务机构管理科 | 服务主体清单、保险状态、发布状态和风险预案 | 补齐资质附件、年度复核、黑名单和服务能力星级评价 |

| 医院接诊回执、导诊交接和 HIS 就诊号映射 | 医疗机构门诊部、信息科 | `hospital-handoff` API、医院回执状态、队列号和导诊提示 | 开展真实 HIS/门诊导诊台联调、异常退回和补证闭环 |
| 合同、保险、补贴类型、费用估算和质量回访 | 老龄服务监管、医保/民政补贴经办、财务部门 | 合同状态、保险状态、补贴分类、质控回访和居民反馈 | 上线电子签章、合同/保险附件、补贴结算和对账报表 |
| 风险队列、投诉处理、审计留痕和发布证据 | 卫健质控部门、投诉受理中心、规划信息/运维安全部门 | 高风险订单、质量回访、任务消息、审计事件和 release 报告 | 增加投诉工单、运营日报、现场签字、告警值守和 SIEM 归档 |

## 下一步开发优先级

1. 生产接入：实名身份、短信网关、电子健康卡、订阅消息和隐私协议上线。
2. 医院联调：HIS 预约号、门诊导诊台、科室联系人、退回补证和医院回执对账。
3. 服务履约：陪诊师移动端签到、轨迹留痕、服务记录、异常上报和居民确认。
4. 保障结算：电子签章、合同/保险附件、补贴资格核验、结算对账和费用明细。
5. 监管闭环：投诉工单、黑名单、星级评价、运营日报、现场签字和 SIEM 审计归档。

## 上线责任分工

| 责任方 | 上线前重点 |
| --- | --- |
| 老龄健康服务部门 | 确认试点服务目录、补贴规则、服务主体准入和质量回访口径 |
| 医疗机构门诊部/信息科 | 完成 HIS/导诊台接口联调、医院回执字段和异常退回流程 |
| 社区卫生服务中心 | 组织居民试点、家属代办确认、现场宣教和线下帮办 |
| 服务机构运营部 | 维护服务主体、陪诊师排班、培训保险和服务履约记录 |
| 医保/民政补贴经办 | 确认补贴资格、费用结算、对账周期和材料留存 |
| 规划信息/运维安全部门 | 负责生产域名、HTTPS、短信/消息通道、监控、日志和审计保全 |
