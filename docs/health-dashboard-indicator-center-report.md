# 卫生健康综合管理服务系统指标中心报告

报告日期：2026-07-07

## 1. 建设目标

指标中心面向各级卫生健康行政部门，吸收标准指标集、国家公立医院绩效考核、等级评审、运营决策和指标下钻思路，把综合驾驶舱从上线准备看板扩展为可审查的指标管理入口。

指标中心不替代国家绩效考核平台、医院 HIS/EMR/LIS/PACS、医保核心、电子证照或统计直报系统，只汇总指标口径、来源、责任方、当前值、目标值、趋势、可信度、阻塞项和下钻入口。

已按《浪潮方案4.1立即采纳开发任务分派表》将“指标中心”和“智慧医院管理线汇聚入口”列入本线程开发计划：先收口指标中心 UI/API/发布证据，再按运营、质量、安全、协同、公卫、科研、资源效率扩展公立医院改革与高质量发展指标，并预留智慧医院、医共体和公卫闭环汇聚入口。

## 2. 已落地能力

| 能力 | 页面/API | 验收口径 |
|---|---|---|
| 指标目录 | `health-dashboard.html#dashboard-indicator-center` | 覆盖公立医院绩效考核、等级评审、医疗质量、运营效率、慢病管理、服务体验/便民惠民、接口联调/上线准备和标准指标集 |
| 指标卡片 | `indicatorCenter.indicators` | 每项展示口径、来源、责任方、当前值、目标值、趋势、状态、质量/可信度和阻塞项 |
| 下钻入口 | `indicator.drilldown.href` | 可跳转人口服务、风险下钻、任务闭环、现场证据、上线门禁和功能报告 |
| 摘要接口 | `/api/health-dashboard/summary` | 返回 `indicatorCenter` 完整结构 |
| 门禁接口 | `/api/health-dashboard/production-readiness` | 返回 `indicatorCenterSummary` 和 `indicatorCenterEvidence` |
| 发布证据 | `npm.cmd run health-dashboard:summary`、`release:report`、`release:manifest`、`deploy:check` | 纳入发布报告、发布清单和部署检查 |

## 3. 指标维度

| 维度 | 责任方 | 当前用途 |
|---|---|---|
| 标准指标集 | 规划信息处、统计信息岗 | 统一指标目录、口径、来源、质量和责任方 |
| 公立医院绩效考核 | 医政医管处、规划信息处 | 对齐国家公立医院绩效考核和高质量发展运营评价 |
| 等级评审 | 医政医管处、项目办 | 支撑四甲/五乙、互联互通测评和现场证据闭环 |
| 医疗质量 | 医政医管处、质控中心 | 追踪高风险事件、处置轨迹和质量阻塞项 |
| 运营效率 | 规划信息处、运行调度岗 | 汇总服务量、任务闭环率、超期率和运营决策信号 |
| 慢病管理 | 基层卫生处、公卫处 | 汇总筛查、随访、教育、用药和医防融合任务 |
| 服务体验/便民惠民 | 妇幼处、基层卫生处、政务服务协同 | 汇总出生、死亡、证照回执和跨部门便民协同 |
| 接口联调/上线准备 | 规划信息处、项目办、安全管理岗 | 关联接口签字、生产后端、审计留存、监控告警和灾备门禁 |

## 4. 公立医院改革与高质量发展分类

| 分类 | 责任方 | 当前口径 |
|---|---|---|
| 运营 | 规划信息处、运行调度岗 | 服务量、闭环效率、运营决策和资源调度 |
| 质量 | 医政医管处、质控中心 | 医疗质量、等级评审、风险下钻和整改复核 |
| 安全 | 安全管理岗、项目办 | 上线门禁、审计留存、灾备演练和安全合规 |
| 协同 | 医政医管处、基层卫生处 | 医共体、转诊、证照交换和跨部门接口协同 |
| 公卫 | 公卫处、基层卫生处 | 慢病、公卫随访、出生死亡和疾控协同 |
| 科研 | 科教处、科研管理岗 | 科研数据集、专病库、转化证据和伦理合规 |
| 资源效率 | 规划信息处、财务运营协同 | 床位、人力、设备、药耗和服务效率 |

## 5. 汇聚入口预留

| 入口 | 当前状态 | 下一步 |
|---|---|---|
| 智慧医院管理线汇聚入口 | 计划中 | 等待医疗质量安全、医院运行监测、科研平台、药品耗材监管子模块完成首轮指标 API 后接入 |
| 医共体协同指标汇聚入口 | 计划中 | 接收医共体协同闭环线程输出的协同效率和闭环完成率 |
| 公卫闭环指标汇聚入口 | 计划中 | 接收公卫风险闭环线程输出的预警、干预和随访指标 |

## 6. 上线边界

当前指标中心可用于演示、联调、上线审查和管理端内部指标口径确认。真实上线前仍需补齐国家绩效考核平台、病案首页、DRG/DIP、等级评审材料、医院源系统、医保核心、电子证照、统计直报、统一身份、生产数据库、审计留存、监控告警和灾备签字。
