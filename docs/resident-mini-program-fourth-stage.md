# T04-MP 第四阶段：可交付发布候选与业务闭环

## 交付判断

第四阶段发布版本为 `1.0.0-rc.4`。软件候选可通过独立脚本构建、校验和回滚，但平台应用标识、正式域名、统一身份、居民授权、消息回执、深链签名和通知服务仍是生产阻断项。模板占位值只会得到“软件候选通过、生产发布阻断”的结果，绝不转换为模拟成功。

## 可打包平台壳

- 微信与支付宝分别提供项目配置模板，共用十一项页面清单和隐私声明映射。
- 微信最低基础库为 `2.27.0`，支付宝最低运行环境为 `2.9.0`。
- 微信应用标识必须符合 `wx` 加十六位十六进制字符，支付宝应用标识必须为十六位数字。
- 即使应用标识格式正确，仍须设置现场核验状态和稳定核验凭据标识；缺少凭据时继续阻断生产发布。
- 接口域名和业务域名必须是无用户名、密码、片段和本地地址的 HTTPS 源。
- `.env.resident-mini-program.example` 只包含显式占位值和默认关闭开关，不含真实密钥。
- 调试开关默认关闭；灰度开关默认关闭；紧急停用默认关闭。灰度启用时必须配置规则标识。

## 发布候选构建

运行：

```text
node scripts/resident-mini-program-release.js
```

默认输出到系统临时目录：

```text
%TEMP%\t04-mp-release-candidate
```

产物包括：

- `release-manifest.json`：版本、构建号、确定性源摘要、页面清单和回滚约定；
- `release-report.json`：软件检查、平台阻断项、生产判断；
- `platform/wechat.project.json`；
- `platform/alipay.project.json`；
- `platform/privacy-map.json`。

构建脚本不依赖根 `package.json`，只允许写入系统临时目录的明确子目录。每次构建先清理该专属目录，输出不包含正式数据、`localhost`、测试凭证、调试语句、敏感日志或英文业务界面。相同源文件生成相同源摘要和清单。

`--production` 模式要求平台配置和五类外部服务全部就绪，否则以非零状态退出：

```text
node scripts/resident-mini-program-release.js --production
```

## 账号与会话闭环

- 首次进入和恢复均使用服务端居民身份回执，不接受本地角色字符串模拟成功。
- 会话剩余五分钟时进入续期；续期器必须由现场注入，并同时返回新会话和服务端身份回执。
- 续期主体、账号或居民不一致、回执缺失、会话过期时强制重新认证。
- 退出、主体变化、账号变化和居民变化清理详情、筛选、在途操作、居民缓存与观测队列。

## 家庭成员切换闭环

- 点击家庭成员后先展示中文确认，不立即切换。
- 确认后进入单航班处理，重复点击被禁用。
- 客户端重新获取居民数据和消息，并再次复用居民关系及授权策略计算范围。
- 只有目标居民仍在最新允许范围时，才原子提交居民、首页、消息和八项服务上下文。
- 网络、服务端或授权失败时保留原居民状态并给出回滚说明。
- 未核验、已过期、已撤回或缺少授权的成员不可切换，并提供重新申请入口。

## 消息与服务闭环

- 消息刷新为单航班；失败保留上次服务端确认状态。
- 页面最多展示一百条，默认十条递增加载，不允许无限列表。
- 本页批量已读最多二十个稳定标识，使用一个稳定幂等键。
- 只有全部服务端回执匹配当前居民并确认已读时才整体提交；半失败整体回滚。
- 撤回、取消和过期消息在进入当前状态前被抑制；安全深链失败退回当前居民页面。
- 八项服务统一提供中文加载、空态、无权限、离线、错误和返回路径；急救拨号及消息写入均防重复操作。

## 隐私安全观测

- 默认关闭，只有居民主动同意后启用；关闭和退出立即清空。
- 只接受启动、页面就绪、请求失败、操作失败和会话临期五类事件。
- 只保留时长、状态码、错误类别、路由、平台和发生时间。
- 居民、姓名、身份证、手机号、病历、诊断、处方、正文、令牌、登录码、对象键、下载地址和审计字段递归脱敏或直接丢弃。
- 离线队列只存在当前应用内存，绑定当前账号会话，最多二十条、最长十五分钟；账号不匹配时清空。

## 发布、灰度与回滚

- 发布清单记录 `1.0.0-rc.4`、构建号和确定性源摘要。
- 灰度开关默认关闭；现场启用时必须登记规则标识、覆盖比例、监测窗口和回退阈值。
- 紧急停用开启时生产门禁直接失败。
- 回滚以已验收源摘要为准，恢复上一构建并同步撤销平台灰度和缓存版本。
- 身份、居民授权、消息幂等、深链签名或通知撤回任一服务未就绪时禁止发布。
